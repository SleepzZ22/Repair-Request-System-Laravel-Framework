# ระบบแจ้งซ่อมอุปกรณ์ไอที (IT Equipment Repair Request System)

ระบบบริหารจัดการและแจ้งซ่อมอุปกรณ์ไอที พัฒนาด้วย **Laravel Framework 12**, **Blade Templates**, **Vanilla CSS**, และ **Chart.js** พร้อมระบบแยกสิทธิ์ตามบทบาทผู้ใช้งาน (Role-Based Access Control) 

---

## 🌟 ฟีเจอร์เด่นของระบบ

1. **ระบบแยกบทบาทผู้ใช้งาน 3 กลุ่ม (RBAC)**:
   - 👑 **ผู้ดูแลระบบ (Admin)**: 
     - แดชบอร์ดสถิติภาพรวม พร้อมกราฟวงกลม (Donut Chart) และกราฟแท่ง (Bar Chart)
     - ตรวจสอบภาระงานของช่างประจำทีมทั้ง 4 คน
     - มอบหมายงานให้ช่างที่เหมาะสมได้โดยตรง
   - 🛠️ **ช่างซ่อมไอที (4 คน)**:
     - ดูกระดานงานส่วนตัว (My Assigned Tasks)
     - คลังงานรอมอบหมาย สามารถ**กดรับงานเองได้ทันที (Claim Ticket)**
     - อัปเดตสถานะงาน (กำลังซ่อม, รออะไหล่, ซ่อมเสร็จ) พร้อมบันทึกผลการซ่อม
   - 👤 **พนักงานทั่วไป (User)**:
     - ส่งใบแจ้งซ่อมอุปกรณ์ใหม่ ระบุประเภท ความเร่งด่วน และแนบรูปภาพปัญหา
     - ดูประวัติงานแจ้งซ่อมของตนเอง และติดตามความคืบหน้าของช่างแบบเรียลไทม์
2. **หน้าติดตามสถานะงานซ่อมแบบสาธารณะ (Public Tracking)**:
   - ค้นหาได้ด้วยรหัสงาน (เช่น `TK-202610-001`) หรือเบอร์โทรศัพท์โดยไม่ต้องล็อกอิน
3. **การแสดงผลขั้นตอนการดำเนินงาน (Visual Progress Stepper)**:
   - กราฟิกแสดง 4 ขั้นตอน: แจ้งเรื่อง ➔ รับเรื่องตรวจสอบ ➔ ซ่อม/เปลี่ยนอะไหล่ ➔ เสร็จสิ้นส่งมอบ
4. **ดีไซน์มินิมอล เรียบหรู (Clean & Minimalist)**:
   - สบายตา ตัวหนังสือคมชัด รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ

## 🚀 วิธีติดตั้งและเริ่มต้นใช้งาน (Installation)

1. **Clone repository**:
   ```bash
   git clone https://github.com/SleepzZ2/Repair-Request-System-Laravel-Framework.git
   cd Repair-Request-System-Laravel-Framework
   ```

2. **ติดตั้ง Dependencies**:
   ```bash
   composer install
   ```

3. **คัดลอกไฟล์ Environment และสร้าง Application Key**:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. **เตรียมฐานข้อมูลและ Seed ข้อมูลเริ่มต้น**:
   ```bash
   php artisan migrate --seed
   ```

5. **รัน Development Server**:
   ```bash
   php artisan serve
   ```
   เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8000`

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
