ระบบแจ้งซ่อมอุปกรณ์ไอที

พัฒนาด้วย Laravel Framework เชื่อมต่อฐานข้อมูล Supabase Cloud

นำเสนอโดย: ทีมพัฒนาโปรเจกต์
01. ปัญหาและแนวคิด

ทำไมต้องมีระบบแจ้งซ่อม?

  • ❌
    ปัญหาเดิม: แจ้งซ่อมผ่านวาจา หรือส่งไลน์
    ทำให้งานตกหล่น ช่างไม่ได้รับเรื่อง และตามสถานะยาก
  • ✅
    สิ่งที่ระบบเข้ามาแก้: รวมศูนย์ทุกการแจ้งซ่อมไว้ที่เดียว
    บันทึกข้อมูลเป็นระเบียบ ตรวจสอบย้อนหลังได้ตลอดเวลา
02. ผู้ใช้งานในระบบ

แบ่งการใช้งานตาม 3 บทบาท

👤
1. พนักงานทั่วไป
เปิดใบแจ้งซ่อม ติดตามความคืบหน้า และดูประวัติของตนเอง
🛠️
2. ช่างเทคนิค (4 คน)
กดรับงานซ่อม (Claim) บันทึกขั้นตอน และอัปเดตปิดงาน
👑
3. แอดมิน
ดูภาพรวมสถิติ จัดสรรและมอบหมายงานให้ช่างแต่ละท่าน
03. ขั้นตอนการทำงาน

การทำงาน 4 ขั้นตอนหลัก

ขั้นที่ 1
เปิดแจ้งซ่อม
กรอกปัญหา ระบุสถานที่ และระดับความเร่งด่วน
ขั้นที่ 2
จัดสรรงาน
แอดมินมอบหมาย หรือช่างกดรับงานเอง
ขั้นที่ 3
ตรวจซ่อม
ช่างเข้าตรวจสอบ บันทึกความคืบหน้า
ขั้นที่ 4
ปิดงานซ่อม
ระบุผลการแก้ และเปลี่ยนสถานะเสร็จสิ้น
04. เทคโนโลยีที่ใช้

สถาปัตยกรรมระบบ

  • ⚡
    Laravel Framework (PHP)
    โครงสร้าง MVC จัดการ Logic ได้ปลอดภัย มีความเสถียรสูง
  • ☁️
    Supabase PostgreSQL (Cloud Database)
    จัดเก็บข้อมูลบนคลาวด์แบบ Real-time เข้าถึงได้จากทุกที่
  • 🎨
    Clean & Modern Frontend
    หน้าตาเรียบง่าย ใช้งานสะดวก และมีระบบสลับสิทธิ์ผู้ใช้ทดสอบ
05. สรุปผลลัพธ์

ประโยชน์ที่ได้รับ

  • 📈
    ลดเวลารอคอย: ช่างทราบงานทันที กดรับงานได้รวดเร็ว
  • 🔍
    โปร่งใส ตรวจสอบได้: มี Timeline บันทึกประวัติทุกขั้นตอน
  • 🖨️
    ส่งมอบงานชัดเจน: มีหน้าสรุปงานเสร็จสิ้นและพิมพ์ใบงานได้
